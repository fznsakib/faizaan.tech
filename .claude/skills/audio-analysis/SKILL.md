# Modify the Audio Pipeline

Key files:
- `src/audio/analysis/analyzeTrack.ts` — build-time onset/energy/section analysis of a full track
- `src/audio/analysis/buildBeatMap.ts` — turns analysis + overrides into a committed `BeatMap`
- `src/audio/analysis/fft.ts` — FFT primitives used by analysis
- `src/audio/beatmaps/*.json` — committed per-track beat maps, generated by `yarn beatmap`
- `src/audio/beatmaps/overrides.json` — manual corrections (keyed by track id) fed into `buildBeatMap`
- `src/audio/frame.ts` — `writeFrame`/`onsetEnvelope`: turns (beat map, song time) into a `MusicFrame` each tick
- `src/audio/MusicEngine.ts` — `writeBands()`: live 6-band spectrum from an `AnalyserNode` (texture only)
- `src/audio/types.ts` — `BeatMap`, `MusicFrame`, `OnsetBand` types

## How Timing Actually Works

Almost everything visual reads from a **precomputed beat map**, not from live beat detection. `yarn beatmap` decodes a track once, analyzes it, and writes a committed JSON file with tempo, downbeat offset, energy/section curves, bar-level intensity, and onset event lists. At runtime, `src/audio/frame.ts`'s `writeFrame()` combines that beat map with the current song time (from the `AudioContext` clock) to produce each frame's `beat`, `bar`, `energy`, etc. — no FFT is involved in that path. See `docs/superpowers/specs/2026-09-25-music-engine-design.md`.

## Live Spectrum Bands (texture only)

In `MusicEngine.writeBands()`:
- `BAND_COUNT` = 6, log-spaced 40Hz–16kHz (`BAND_EDGES`)
- `AnalyserNode`: `fftSize` 1024, `smoothingTimeConstant` 0 (no built-in smoothing — components smooth themselves, e.g. `vuStep` in `SubtitleStack`)
- Each band's mean dB goes through a `BandNormaliser` (`src/audio/bands.ts`): a per-band adaptive range, time-based (`dt` in seconds), so loud passages still span 0..1 instead of clipping at a fixed ceiling
- `BAND_RANGE`: peak attacks instantly and releases over `peakRelease` 2s; the floor falls fast (`floorFall` 0.25s) and rises slowly (`floorRise` 4s); span clamped to `minSpan` 12dB…`maxSpan` 24dB; below `SILENCE_DB` (-100) a band is 0

These bands are for visual texture only (`frame.bands`), not for detecting the beat.

## Onset Envelopes (kick/snare/hat)

- Committed in `BeatMap.onsets` as flat `[t0, s0, t1, s1, …]` event lists (seconds, strength 0..1), produced by `analyzeTrack`/`buildBeatMap`.
- `onsetEnvelope()` in `frame.ts`: instant attack, exponential decay per `ONSET_DECAY` (kick 0.18s, snare 0.14s, hat 0.07s). Advances a per-band cursor in `FrameCursors`, reset on seek/play/track switch.

## DJ-Mode Hits (visitor-triggered stab/kick/snare/hat)

- `engine.hit(voice, nowMs)` in `MusicEngine.ts` unlocks audio, then schedules the hit.
- If a track with a beat map is playing, the hit snaps to the nearest 16th note via `sampler/quantize.ts`'s `nearestSixteenth()` (based on what the visitor is about to *hear*, compensating for scheduling lead); otherwise it plays immediately.
- `HitLog` (`sampler/hits.ts`) tracks recent hits and drives `frame.stab`, `frame.stabHit`, and `frame.jamming` (a hit landed within `JAM_WINDOW` while no track plays).
- `sampler/voices.ts`'s `playVoice()` synthesizes each voice from a shared noise buffer plus per-voice gain/frequency envelopes — no audio assets for DJ mode.

## Adding a New MusicFrame Field

1. Add the field to `MusicFrame` in `src/audio/types.ts`.
2. Initialize it in `createFrame()` (`frame.ts`).
3. Reset it in `clearFrame()` if it should zero out with no beat map.
4. Compute it in `writeFrame()` (beat-map-derived) or in `MusicEngine.update()`/`writeBands()`/`applyHits()` (live-signal- or hit-derived).
5. Consume it via `useMusicFrame()` in the target component.

## Adding/Fixing a Beat Map

1. Drop the mp3 in `src/assets/audio/`.
2. Run `yarn beatmap <file.mp3> [--id <id>]` (uses `afconvert` to decode, then `analyzeTrack` + `buildBeatMap`).
3. If tempo/downbeat detection is off, add or edit an entry for that track's id in `src/audio/beatmaps/overrides.json`, then re-run.
4. Add the track to `src/audio/tracks.ts` (see that skill's or `CLAUDE.md`'s "Adding a New Song" steps). `src/audio/tracks.test.ts` enforces that every mp3 in `src/assets/audio/` has exactly one matching entry with a committed beat map — run `yarn test` to check.

Don't hardcode the current song list here — check `src/audio/tracks.ts` for the live crate.
