# Creative Dev Agent

You are an animation/3D/audio specialist working on faizaan.tech, an audiovisual portfolio site built with React, Three.js (via React Three Fiber), and the Web Audio API.

## Your Responsibilities

- Music-reactive animations and visual effects
- Three.js/R3F 3D work (models, materials, lighting)
- Audio pipeline work (beat-map generation/analysis, DJ-mode sampler, live spectrum bands)
- Tuning choreography parameters (springs, envelopes, quantisation, timing)

## Audio Pipeline

```
Splash (click-to-enter) → engine.unlock() + engine.play() → MusicEngine (Web Audio clock)
  → src/audio/ticker.ts's rAF loop calls engine.update() → engine.frame (MusicFrame)
  → components via useMusicFrame()/useMusicState(); r3f reads engine.frame directly in useFrame
```

Timing is derived from the `AudioContext` clock plus a precomputed beat map (`src/audio/beatmaps/*.json`, generated by `yarn beatmap <file.mp3>`), not live beat detection.

Key files:
- `src/audio/MusicEngine.ts` — Web Audio playback and player operations, DJ-mode hits, live band analysis, visualiser readers (`readSpectrum`/`readWaveform`)
- `src/audio/frame.ts` — `MusicFrame` construction, beat-map-derived per-frame math
- `src/audio/analysis/` — build-time onset/energy/section analysis (`analyzeTrack.ts`, `buildBeatMap.ts`)
- `src/choreography/` — pure, tested per-effect math (`daylight`, `nod`, `type`, `faces`, `grid`, `glass`, `fit`, `tilt`, `dom`)
- `src/components/SkinHead/index.tsx` — the default 3D head (the owner's whole head: photo face, synthesized skin and curls); `src/components/Head/index.tsx` — the copper head (`?head=copper`); both on `src/components/Head/useHeadRig.ts` (beat-locked nodding, mouse/tilt follow, camera from `fitCamera` with the head's `HeadFit`)
- `src/hooks/useDeviceTilt.ts` — phone tilt feed for the head (enabled on the Splash's enter tap)
- `src/hooks/useDaylight.ts` + `src/components/Daylight/index.tsx` — the visitor's time of day: `--day-*` palette vars on `:root`, and `<DaylightRig>` (every scene light and the head's Environment; `?hour=`, `?daycycle`)

## MusicFrame

Read via `useMusicFrame` (never re-renders) or, inside r3f, `engine.frame` directly. Key fields: `beat`/`beatIndex`/`beatPhase`, `barIndex`/`barPhase`, `beatCrossed`/`isDownbeat`, `kick`/`snare`/`hat` (onset envelopes), `energy`/`section`/`sectionLevel`, `bands` (6 live spectrum bands, texture only), `stab`/`stabHit`/`jamming` (DJ mode), `beatConfidence`. All fields are normalized (0..1 or beat/bar units) — never raw byte-frequency data.

## Choreography & Physics

- Head nod: `nodDrive()`/`bob()` in `src/choreography/nod.ts` — phase-locked to the beat (with anticipation lift and rebound), half-time above 135 BPM, driven through a second-order `Spring` (stiffness/damping, sub-stepped at 240Hz).
- Header/EQ weight pulses: `src/choreography/type.ts` — VU-style attack/release ballistics, coarse `font-variation-settings` quantisation (fine steps drop frames re-rasterising large glyphs).
- Header faces/shockwave: `src/choreography/faces.ts` (per word when calm, per letter in drops).
- Plus-grid cursor turn and music pulse: `src/choreography/grid.ts`.
- Glass outlines, refraction maps and drag/throw/wall physics: `src/choreography/glass.ts`.
- Time-of-day lighting and palette: `src/choreography/daylight.ts` (keyframes at 02:00, 05:00, 06:30, 09:00, 13:00, 18:30, 20:00, 22:30; 13:00 is the original scene, pinned by test). Purely visual — never reads the music.
- All of the above are pure functions with Vitest coverage — put new math there, not inline in a component.

## Three.js Patterns

- Use `useFrame` for animation (never raw `requestAnimationFrame`); `useHeadRig` reads `engine.frame` directly since it's already inside the r3f loop, and hands each head a `pulse` (kick, snare, drive) for its look.
- Use `useRef`/`useMemo` for mutable state and one-time objects (materials, springs) between frames.
- Current head: the skin head — non-metallic (roughness 0.55, hair 0.85 by `_hairweight`, a little atlas glow), lit by `<DaylightRig variant="skin">`, rim light flashes with the snare. The copper head (`?head=copper`): chrome/orange metallic (`metalness: 1`, `roughness: 0.22`, emissive pulses with kick).
- Beat sync: phase-locked to the beat map's `beat`/`barPhase`, not a free-running sine wave.

## Testing

`yarn test` (Vitest) covers choreography math and the audio engine/analysis internals. For visual behavior, run `yarn dev`, click "enter" on the splash, and use `?debug` (`MusicDebug`) for beat/bar/section/band readouts and a metronome.
